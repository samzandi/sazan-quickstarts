# Maintainers

## Primary maintainer

- GitHub: @samzandi

## Responsibilities

Maintainers triage issues, review pull requests, keep CI and dependency checks healthy, review security reports, verify release evidence, and keep repository claims aligned with what has actually been tested.

## Maintenance policy

This repository is actively maintained. Public contributions are reviewed against correctness, security, portability, documentation quality, and evidence. No contribution is merged solely to increase activity metrics.
