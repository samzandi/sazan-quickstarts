# v0.1.0-rc.1 Release Candidate

Status: **release candidate preparation; not yet published; not production-ready**

## Purpose

This is the first Sazan Quickstarts release candidate. It packages the currently implemented provider-neutral quickstarts and repository-level safety/readiness controls into a versioned pre-release candidate.

## Candidate version

`v0.1.0-rc.1`

## Included scope

- agent-starter
- browser-agent
- computer-agent
- coding-agent
- customer-support-agent
- document-agent
- email-agent
- research-agent
- business-agent
- reviva-agent
- mcp-starter

## Required release evidence

Before this candidate can be published as a GitHub pre-release:

1. Repository Validation must be green.
2. Release Gate must be green on the exact release-candidate commit.
3. The resolved dependency set must be captured as `release-dependencies.txt`.
4. Resolved dependency license metadata must be captured as `third-party-licenses.json`.
5. No package in the generated license snapshot may have missing/UNKNOWN license metadata without explicit manual review.
6. The exact commit intended for the tag must be recorded.

## Current boundaries

This repository remains pre-release and is not production-ready. Current evidence does not establish deployment safety, internet-scale abuse resistance, full privacy/security controls, availability objectives, observability, incident response, or workload-specific correctness.

## Release naming

If all gates pass, the intended first tag is `v0.1.0-rc.1` and it should be published as a GitHub pre-release, not a stable release.
