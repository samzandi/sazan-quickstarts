# Open-Source Maintenance

Sazan Quickstarts is maintained as a public, reusable set of provider-neutral AI-agent examples.

## What maintainers actively review

- bug reports with a reproducible case
- pull requests with tests and bounded scope
- dependency and security changes
- provider compatibility regressions
- documentation claims that exceed the evidence
- release readiness for tagged versions

## Evidence over activity

Repository health is measured by verified behavior, useful issues, reviewed changes, security posture, and reproducible releases. Stars, forks, and download counts may be recorded when available, but the project does not manufacture activity or claim adoption that cannot be verified.

## AI-assisted maintenance

AI tools may help triage issues, review pull requests, prepare tests, analyze failures, and draft release notes. Maintainers remain responsible for final review, authorization, security decisions, and release approval.

## Release policy

A release or pre-release is published only when the checks in `docs/RELEASE_CHECKLIST.md` are satisfied for the exact target commit.
